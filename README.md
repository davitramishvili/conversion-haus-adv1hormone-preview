# conversion-haus-adv1hormone-preview

Static preview of the **adv1hormone** landing-page clone, built as a test task for The Conversion Haus agency. Cloned from the original advertorial at `womenshealthyreport.com/adv1hormone`.

This repo holds the rendered static HTML/CSS preview only. The full Shopify Liquid theme source (Dawn-based) lives in a separate private repo.

## View live

The static preview can be served from any web server:

```bash
npx serve .
# or
python -m http.server 8080
```

## Stack (preview)

- HTML
- CSS
- Static assets (images, fonts)

## Stack (theme source, private)

- Shopify Liquid (Dawn 15.x)
- Section + block schema
- Vanilla JS for interactive elements
